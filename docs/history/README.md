# Project history archive

These files are a **local, permanent copy of the original Codex chat
transcript** that this project was built in (roughly 8 sessions, ~120 user
turns) before Claude took the project over on 2026-09-02.

They exist so that **no future session ever needs to re-fetch the ChatGPT
share link.** That link is read-only, can disappear, and fetching + parsing
it costs a large amount of usage every single time. Read these files
instead.

| File | What it is |
|---|---|
| `codex-transcript-user-turns.txt` | **Read this one first.** Just the user's ~120 messages, extracted. This is where all the game-mechanics corrections, priorities and complaints live. ~29 KB. |
| `codex-transcript-full.txt` | The complete transcript including all assistant replies. ~182 KB. Only open this if the user-turns file doesn't answer the question. |

Before reading either, check whether the answer is already distilled in:

- `KNOWN_MISTAKES.md` — corrections the user made, and regressions not to reintroduce
- `PROJECT_STATE.md` — what this project is and where things live
- `NEXT_PHASE.md` — what's left to do
- `knowledge-pack/PLAYER_KNOWLEDGE.md` — canonical Farm RPG game facts

Those were written *from* these transcripts specifically so the transcripts
usually don't need to be opened at all.
