Installing and connecting the account sync

Three steps, once, in Chrome, Brave or Edge.

  1. Install it

    Download the extension and unzip it somewhere you will keep it.

    Open chrome://extensions (or brave://extensions, edge://extensions), turn on Developer mode, choose Load unpacked and pick the farm-rpg-account-sync folder.

  2. Check its permissions

    Open Details on the extension. It only asks for these sites:

    • https://farmrpg.com/*the game pages it reads
    • https://www.farmrpg.com/*the same site
    • file:///*this planner, if you opened it from a downloaded copy
    • http://localhost/*this planner, run on your own computer
    • http://127.0.0.1/*the same
    • https://alikdash1.github.io/Farmrpgcalculator/*this planner's website

    Using the downloaded copy? Also switch on Allow access to file URLs.

  3. Visit your pages

    Keep this planner open in a tab, refresh Farm RPG once, then open your profile, Inventory, Tower, Mastery, Quests and farm pages. That's it — from then on it updates as you play.
