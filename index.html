Setup

Installing and connecting the account sync

Three short steps, done once. After that it keeps itself current while you play.

  1. Install it

    Open brave://extensions and switch on Developer mode (top right). Choose Load unpacked and pick this folder:

    calculator\collectors\account-sync-extension

    If it is already installed, press the reload arrow on its card instead — an older copy will not have the newest behaviour.

  2. Give it the two permissions it needs

    Open Details on the extension card. Under site access, these five addresses are the complete list — it asks for nothing beyond them:

    • https://farmrpg.com/*the pages it reads
    • https://www.farmrpg.com/*the same site, other spelling
    • file:///*this planner, opened from your disk
    • http://localhost/*this planner, if you serve it
    • http://127.0.0.1/*the same, by number

    Then switch on Allow access to file URLs. This one is easy to miss and nothing works without it: you open this planner by double-clicking a file on your disk, and without that switch the extension is not allowed to speak to it.

  3. Connect it to this page

    Leave this planner open in a tab. The status panel above changes from Waiting for extension as soon as they find each other, and every later capture arrives here on its own.

    Still waiting? Reload the extension, check the file URL switch, then reload this page.

Using it day to day

You do not press anything. Every Farm RPG page reads itself once it finishes loading, so the pages you visit while playing are already saved.

It keeps one capture per page and the newest wins, so visiting your inventory fifty times leaves one record, not fifty.

Capture this Farm RPG page is only for a page that changed after it loaded — you crafted something while sitting on your inventory and want the new number without refreshing.

Click the extension icon to see all twelve sections with how old each one is, and an Open button that takes you to that page, which then captures itself.

Without leaving it running

Press Save account snapshot to Downloads in the extension. You get one file, lantern-ledger-account-snapshot.json, which overwrites itself rather than piling up numbered copies.

Bring it back here with Load a saved file instead above, check what it found, then press Apply confirmed values.

Leave Keep that file updated after every capture ticked and the file stays current by itself.

What it will not do

It never clicks, plays, or navigates Farm RPG for you. It reads pages you open, and tells you which ones have gone stale — you stay the one deciding to go there.

Nothing is uploaded. Captures live in your browser and in the file you save yourself.
